建模逻辑

禅茶300期的数据给了我们一个基准：平均每期约5-6人（假设多数场次在中间值），123人的微信群是现有社群天花板，实际活跃转化率按20%估算，也就是约25人是真实的潜在首批用户。
正念咖啡是新品牌，从禅茶迁移客户用一个衰减系数k=0.3（品牌不同、形式不同、不是所有禅茶学员都会来），所以起点预估约7-8人/期。
之后的增长用S型曲线（Logistic函数）建模，原因是社群增长不是线性的——初期慢、中期加速、后期趋于饱和。慕尼黑目标受众有限，把单次活动人数上限设为30人作为饱和点。
